# 演员 AI 团队工作台 · A/B 端整合题案

更新日期：2026-10-23

在线题案：https://kelen1421.github.io/actor-studio-proposal/

## 内容

- A 端个人创作与决策、B 端九项后勤执行模块。
- 日程申请、本人变更、任务发布与图文留痕的协作流程。
- 账号、项目及敏感字段授权、留痕编辑和版本历史。
- A 端智能体六项能力、三条交互示例、本人确认边界和首轮优先项。
- A 端加密、云端只实时转发密文、B 端解密的目标架构；支持切换反向流程。
- 离线由发送端排队、本地留痕与加密备份、最少元数据和模型服务留存边界。

## 使用

`index.html` 是样式、脚本和示意图片均已内嵌的静态网页，可以直接打开，也可用 GitHub Pages 展示。首选字体为微软雅黑，未安装时使用系统回退字体；未分发字体二进制文件。

本仓库只包含题案与虚构演示资料，不含真实剧本、私人行程、数据库、凭据或本机上传内容。网页不会连接本地软件，不提供真实登录、任务发布或审批。

## 实现状态

保留题案整理时的本机验证记录。智能体、端到端加密、设备密钥管理和云端不留存业务内容均为后续接入与验收规划；网页中的交互示例不代表这些能力已经实现。

“云端不留存”针对拟建业务中转服务的正文、图片、附件及其密文；公开题案 HTML 本身由 GitHub 与 GitHub Pages 托管。身份、设备、公钥与必要路由等最少元数据需要单独制定保留政策。私密 AI 优先本地处理，外部模型需单独授权并核实留存政策。
